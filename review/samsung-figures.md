## 우리 애니메이션으로 만들 개념 후보 (위 원문 기준)
1. 웨이퍼 제조: Cz 결정 성장(seed 끌어올리기) → 다이아몬드 톱 슬라이싱 → 연마 / 웨이퍼 부위 이름(다이·스크라이브 라인·플랫존·노치)
2. 산화: 고온 로에서 SiO₂가 자라는 모습, 건식(O₂, 얇고 치밀함)과 습식(O₂+H₂O, 5~10배 두꺼움) 비교
3. IC: 웨이퍼 → 다이 → 소자로 확대해 들어가기, 소자 4종의 역할(스위치·창고·조절·신호)
4. 포토: 마스크(석영+크롬) → PR 도포 → 노광(축소 투영, 스텝 앤 리피트) → 현상, 양성/음성 PR 비교
5. 식각: PR 마스크 아래만 남기고 깎기, 습식과 건식 비교, 플라즈마 생성(전자 충돌 → 이온화 → 연쇄 반응 → 라디칼)
6. 증착·이온주입: PVD와 CVD 비교, 박막이 층층이 쌓임(빌딩 비유), 이온 빔 주입 → n형/p형
7. 금속 배선: Al 배선 + 베리어 메탈, 좁은 콘택 홀은 W CVD로 채움
8. EDS: 프로브 카드 핀 접촉 → 4단계 흐름 → 웨이퍼 맵의 양품/불량(Inking) → 수율 계산
9. 패키징: 다이싱 → 다이 어태치 → 와이어본딩과 플립칩 비교 → 몰딩 → 패키지 테스트
