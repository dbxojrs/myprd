## 새 규칙 후보 (출처 있음, 아직 앱에 없음)
- 다이 어태치 조건 → 보이드, 다이 깨짐 (마이크로전자및패키징학회지 2025, KETI DAF 리뷰)
- 레이저 마킹이 너무 깊음 → 패키지 약화, 칩 손상 (마이크로전자및패키징학회지 2022, SK hynix)
- 패키지 쏘잉: 절단 경로의 구리 → 버·번짐, 몰드 → 칩핑, 블레이드 마모 → 치수 불량 (ADT QFN 싱귤레이션, DISCO QFN)

## 확인하지 못한 것
- SK hynix 뉴스룸: 자동 접근이 막혀(403) 열지 못했습니다. 전공정·후공정 연재가 있으니 사람이 직접 확인해 추가할 만합니다.
- JEDEC 표준 페이지(JESD22, J-STD-020): 자동 접근이 막혀 넣지 못했습니다. 회원 가입 후 직접 확인이 필요합니다.
- IEEE EPS Heterogeneous Integration Roadmap: 확인한 주소가 404였습니다.
- 전공정의 근거 출처(논문): 아직 찾지 않았습니다. KCI·DOAJ에서 공정별로 찾아야 합니다.
- 삼성 6탄에는 ALD·열처리, 7탄에는 CMP 설명이 없습니다. 앱 설명의 이 부분은 다른 출처가 필요합니다.
- 마킹, 최종 테스트: 재사용이 허락된 실제 사진을 찾지 못했습니다.

## 사진 사용 시 주의
- 다이 어태치 사진은 세라믹 패키지, 몰딩 사진은 BGA 단면입니다. QFN이 아니라서 제목에 밝혀 두었습니다.
- MIT OCW는 CC BY-NC-SA(비영리)입니다. 앱을 유료화하면 링크 방식으로 바꿔야 합니다.
- CC BY-SA 사진은 저작자와 라이선스를 계속 함께 표시해야 합니다(앱의 사진 설명에 표시 중).

## 영상 링크 (공식 채널만)
- 웨이퍼 쏘잉: 한미반도체 공식 채널, ADT 공식 채널 영상 2개를 넣었습니다. 채널은 각 회사 홈페이지의 링크로 공식 채널임을 확인했습니다.
- 웨이퍼 쏘잉 후보(제외): DISCO 공식 채널의 "Kiru실험 블레이드 다이싱" 편은 광고용 CG 위주라 넣지 않았습니다.
- 패키지 쏘잉: 공식 채널 영상을 찾지 못했습니다. Semitracks(반도체 교육 회사) 채널의 30초 애니메이션이 있지만 허용한 채널 종류 밖이라 넣지 않았습니다.
- 영상 내용은 제목·설명으로만 확인했습니다(유튜브 로그인 요구로 직접 시청은 못 함). 사람이 한 번 보고 확인해야 합니다.

## 알아둘 점 사진 (2026-10-31)
- 앱에 넣은 사진(CC BY 4.0 논문 그림): 블레이드 날 끝 SEM(Materials 2022), 커프·칩핑(Scientific Reports 2020), 다이 둘레 접착제 검사(Sensors 2025), 볼 본드 SEM(Micromachines 2023), 몰딩 보이드 X선(Sensors 2017). 논문의 자체 실험 그림만 골랐습니다.
- 링크만 둔 것(재사용 불가): DISCO 블레이드 SEM, KEYENCE 마킹 사진, DISCO QFN 버, DISCO 웨이퍼 휨(설명 그림), Trio-Tech 번인 보드.
- Trio-Tech 페이지는 자동 확인에서 406(봇 차단)이 나왔습니다. 조사 때는 열렸으니 사람이 한 번 열어 확인해야 합니다. 같은 페이지의 다른 그림 일부는 AI 생성 이미지라서 링크만 둡니다.
- 찾지 못함: DAF 실제 사진, 와이어 쓸림 X선 사진, 다이 어태치 보이드 사진(Semitracks SAM 사진은 허용한 출처 종류 밖이라 제외), 필렛을 옆에서 본 사진.
- 볼 본드·몰딩 보이드 사진은 QFN이 아닌 시험용 시료입니다(제목에 맞게 적음). 블레이드 SEM은 소결 금속 결합재 블레이드라 니켈 전주 블레이드와 조금 다릅니다.

## 고급 장비 시뮬레이터 숫자 근거 (2026-11-12 확인)
| 숫자 | 출처 | 위치 |
|---|---|---|
| 열초음파 본딩: 온도 100–150 °C, 하중 20–200 gm, 초음파 60 kHz · 1–5 W, 시간 20–200 ms | TPT Wire Bonding Basics (UCSB 위키 PDF) | 4쪽 "5. Energy Methods" |

| 주축 30,000 min⁻¹, 이송 60 mm/s, 프리컷 실험 10~60 mm/s, 풀컷 400 µm | DISCO ZH05 제품 페이지 | 실험 조건 표 |
| 입자 #2000(일반)·#4800(고운 입자, 얇은 웨이퍼 뒷면 칩핑 감소), 고운 입자의 눈막힘, 50 µm 이하 얇은 다이 | DISCO Dicing Thin Wafers | 본문 |

- DISCO TR16-03 PDF에는 "30 µm or less"(칩 두께) 외에 다이싱 조건 숫자가 없었습니다.
