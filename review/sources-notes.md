## 라인 실습 규칙과 근거
| 규칙 (lineSim.js) | 근거 |
|---|---|
| 너무 얇은 웨이퍼 → 쏘잉에서 칩핑·크랙 | 마이크로전자및패키징학회지 2011 (두께별 파단강도), DISCO "Dicing Thin Wafers" |
| 빠른 몰딩 주입 → 와이어 쓸림 | 한국정밀공학회지 1996 (런너 균형·램 속도 제어로 와이어 스윕 감소) |
| 약한 초음파 출력 → 접합 안 됨, 강하면 크레이터링 | TPT "Wire Bonding Basics" 문제 해결 표 |
| 접착제 과다 → 패드 오염 → 와이어 접합 약화 | TPT "Wire Bonding Basics" (패드 오염이 접합 불량 원인). 업계 잡지 기사(TI 저자)도 있었지만 허용 목록 밖이라 제외 |

## 새 규칙 후보 (출처 있음, 아직 앱에 없음)
- 다이 어태치 조건 → 보이드, 다이 깨짐 (마이크로전자및패키징학회지 2025, KETI DAF 리뷰)
- 레이저 마킹이 너무 깊음 → 패키지 약화, 칩 손상 (마이크로전자및패키징학회지 2022, SK hynix)
- 패키지 쏘잉: 절단 경로의 구리 → 버·번짐, 몰드 → 칩핑, 블레이드 마모 → 치수 불량 (ADT QFN 싱귤레이션, DISCO QFN)

## 확인하지 못한 것
- SK hynix 뉴스룸: 자동 접근이 막혀(403) 열지 못했습니다. 전공정·후공정 연재가 있으니 사람이 직접 확인해 추가할 만합니다.
- JEDEC 표준 페이지(JESD22, J-STD-020): 자동 접근이 막혀 넣지 못했습니다. 회원 가입 후 직접 확인이 필요합니다.
- IEEE EPS Heterogeneous Integration Roadmap: 확인한 주소가 404였습니다.
- 전공정의 근거 출처(논문): 아직 찾지 않았습니다. KCI·DOAJ에서 공정별로 찾아야 합니다.
- 삼성 6탄에는 ALD·열처리, 7탄에는 CMP 설명이 없습니다. 앱 설명의 이 부분은 다른 출처가 필요합니다.
- 마킹, 최종 테스트: 재사용이 허락된 실제 사진을 찾지 못했습니다.
