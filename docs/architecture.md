## AI 근거 검색 흐름 [가설]
1. 학생 질문이 공정 데이터로 답할 수 있으면 AI를 부르지 않습니다.
2. 데이터에 없으면 서버가 무료 API(OpenAlex, Semantic Scholar, Crossref)로 논문을 찾고, Unpaywall·CORE로 무료 본문을 찾습니다.
3. AI는 찾은 자료 안에서만 요약하고, 문장마다 출처를 붙입니다.
4. 출처가 없는 문장은 지우고, 남는 내용이 없으면 "검증된 자료에서 확인되지 않음"을 보여줍니다.
5. 요약 내용이 공정 데이터와 다르면 공정 데이터를 보여주고, 차이를 검토 목록에 남깁니다.

## 라인 시뮬레이션 판정 순서 [가설]
1. 학생이 공정마다 선택지를 고르면 lineRun에 저장합니다.
2. 마지막 공정이 끝나면 각 선택지의 기본 등급을 lineOptions에서 읽습니다.
3. lineRules를 앞 공정부터 적용해 뒤 공정의 등급을 바꿉니다.
4. 불량이 하나라도 있으면 불량, 주의만 있으면 신뢰성 위험, 모두 권장이면 정상으로 판정합니다.
5. 등급이 가장 나쁜 선택지를 원인으로 보여주고, 연결 규칙으로 바뀐 경우 두 공정을 함께 보여줍니다.
6. "이전 공정"으로 선택을 바꾸면 2번부터 다시 계산합니다.

## 질문 (기업·전문가 인터뷰용)
- 저장 위치: 학습 기록을 브라우저에만 둘지, 여러 기기에서 이어 보도록 서버에 둘지
- 권한: 공정 데이터를 고치는 검수자 화면이 필요한지, 누가 검수자인지
- API·DB: AI 검색을 위한 서버를 둘지, 무료 API의 호출 한도는 충분한지
- 실패 조건: 무료 API가 응답하지 않거나 AI 응답이 늦을 때 화면에 무엇을 보여줄지

## 구조도 위험 1개
AI 근거 검색은 무료 API와 AI 모델이라는 두 외부 서비스에 의존합니다. 둘 중 하나가 실패하면 질문 기능이 멈출 수 있으므로, 첫 버전은 **검수된 공정 데이터만으로도 모든 화면이 동작**하게 만들고 AI 검색은 추가 기능으로 둡니다.

## 구조도 질문에 대한 답 (v1 "질문" 확정)
| 질문 | 결정 |
|---|---|
| 저장 위치 | 기본은 그 브라우저의 localStorage. 로그인하면 Supabase `study_data`에도 저장하고, 로그인할 때 기기 기록과 합침(노트·보고서는 더 최근에 고친 쪽). 계정 기록을 받기 전에는 올리지 않음 |
| 권한 | 학생 본인 기록만 읽고 씀(RLS). 검수자 화면은 만들지 않음(검수 절차만 정의) |
| API·DB | 서버 없이 Supabase(인증·DB)만 사용. v1에 [가설]로 둔 "서버 AI 근거 검색(무료 논문 API)"은 만들지 않음 — 출처는 사람이 원문을 확인해 출처 목록에 넣음 |
| 실패 조건 | Supabase가 응답하지 않거나 설정이 없으면 로그인 버튼만 숨기고 브라우저 저장으로 계속 동작. AI 키가 없거나 호출이 실패하면 AI 기능만 안내 문구를 보이고 나머지는 그대로. 장비가 알람으로 멈추면 다음 공정으로 넘어갈 수 없음 |

## 현장 시나리오 판정 순서
1. 선택지(초기 대응·조치·검증)마다 기준별 점수와 가상 시간이 정해져 있습니다. 하나만 고르는 노드는 선택지의 next로 결과가 갈립니다.
2. 확인한 데이터마다 데이터 점수가 있고, 확인에는 가상 시간이 듭니다(단계 예산 안에서).
3. 가설은 맞을 때만 점수(첫 시도 만점, 두 번째 절반)와, 맞는 가설을 뒷받침한 근거 점수를 줍니다.
4. 기준별 합을 0~배점으로 자르고 더해 100점 만점을 만듭니다. 평가 모드는 힌트 1단계마다 2점을 빼고, 제한 시간을 넘기면 시나리오 규칙대로 감점합니다.
5. 같은 선택이면 항상 같은 점수가 나옵니다. `npm run check-content`가 시나리오 연결(노드·데이터·부위·미디어 id)과 배점 합을 검사합니다.

## FAB 공정 시뮬레이션 판정 순서
1. 공정마다 상태·조건 단계로 설비 규칙표의 규칙을 찾습니다. 알람이 있으면 그 공정은 진행할 수 없습니다.
2. 전체 흐름에서는 앞 공정의 조건·결과가 라인 연결 규칙에 맞으면 뒤 공정의 상태를 바꾸고(잠금 표시), 끝까지 남는 영향(final)을 모읍니다.
3. 최종 판정은 공정별 판정과 끝까지 남은 영향 중 가장 나쁜 것입니다(불량 > 신뢰성 위험 > 정상).
4. 웨이퍼 단면 그림은 판정 제목과 상대 지표로만 모양을 정합니다(같은 조건이면 같은 그림).

**근거 등급**: 설비 규칙 175개 중 65개와 현장 시나리오 일부 원인이 2순위(설명 출처)에 기대고 있습니다. 판정 계산은 규칙표로 일정하지만, 규칙 자체가 틀리면 학생이 틀린 인과를 배웁니다. PRD v2 예외 규정대로 화면에 "설명 출처·검수 전"을 표시하고, 1순위 출처로 바꾸는 작업과 현직자 검수를 다음 단계로 둡니다.
