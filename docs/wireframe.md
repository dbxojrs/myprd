# 와이어프레임: 반도체 패키징 공정 튜터
작성일: 2026-10-17

> PRD의 Q4 기능, Q5 화면, Q6 성공 기준을 화면 위치로 약속합니다. 입력칸, 버튼, 누른 뒤 결과, 실패 조건을 구현 전에 정합니다.

## 화면 요약표
| 화면 | 입력·버튼 | 누른 뒤 결과 | 실패·미확인 조건 | 연결할 Q6 |
|---|---|---|---|---|
| 1. 패키지 선택 | 패키지 버튼(QFN, BGA, 플립칩, WLCSP, 팬아웃), [학습 시작] | 설명 카드(장점, 쓰이는 곳, 대표 제품) 표시 → 학습 시작 시 흐름도로 이동 | QFN 외 패키지는 "설명만 제공, 공정 상세 준비 중" 표시 | QFN 버튼 → 설명 → 흐름도 열림 |
| 2. 공정 흐름도 | 공정 칸 클릭, [패키지 바꾸기], [라인 실습 시작] | 공정 칸 → 공정 질문 화면, 라인 실습 → 라인 시뮬레이션 1단계 | 학습 기록이 없으면 모든 칸이 "미학습" | 패키지를 바꾸면 흐름 순서가 바뀜 |
| 3. 공정 질문 | 검색창, [검색], 추천 공정 버튼, [학습 완료], [틀린 내용 신고] | 설명·용어·출처·"먼저 볼 공정" 표시, 학습 완료 시 흐름도에 체크 | 빈값: "공정 이름을 입력하세요" / 이름 겹침: "웨이퍼 쏘잉인가요, 패키지 쏘잉인가요?" / 근거 없음: "검증된 자료에서 확인되지 않음" | "쏘잉 알려줘" → 설명 + 선수 공정 + 출처 |
| 4. 공정 시뮬레이션 | 조건 슬라이더 2–3개, [실행] | 결과, 대표 불량, 이유 한 문장 | 규칙표에 없는 조합: "이 조합은 아직 자료가 없습니다" | 조건을 바꾸면 결과와 이유가 바뀜 |
| 5. Advanced Package | 첨단 패키지 카드, 탭 4개, "먼저 볼 기본 공정" 버튼 | 탭 내용과 출처·날짜 표시, 기본 공정 버튼 → 공정 질문 | 출처 날짜가 6개월 이상 지나면 "검토 필요" 표시 | 2.5D 카드 → 탭 4개, 탭마다 출처 1개 이상 |
| 6. 라인 시뮬레이션 | 선택지 1·2·3, [이전 공정], [다음 공정] | 다음 공정으로 이동, 진행 막대 증가, 마지막 공정 뒤 최종 판정으로 이동 | 선택하지 않고 다음: "선택지를 하나 고르세요", 다음 버튼 비활성 | 이전으로 돌아가 바꾸면 판정 재계산 |
| 7. 최종 판정 | [이 공정 다시 학습], [처음부터 다시], [선택 요약 펼치기] | 학습 → 원인 공정의 질문 화면, 다시 → 1단계로 선택 초기화 | 연결 규칙이 없으면 "연결: 없음" 표시 | 권장만 → 정상 / 불량 하나 → 불량 + 원인·이유·출처 |

## 1. 패키지 선택
```
┌───────────────────────────────────────────┐
│ 패키징 공정 튜터                [Advanced]  │
├───────────────────────────────────────────┤
│ 학습할 패키지를 고르세요                     │
│ [ QFN ] [ BGA ] [ 플립칩 ] [ WLCSP ] [ 팬아웃 ]│
├───────────────────────────────────────────┤
│ QFN · 리드프레임 패키지          [검수됨]    │
│ 장점: 작고 얇음, 저렴함, 열 방출 좋음         │
│ 쓰이는 곳: 전원 관리 IC, MCU, 자동차·IoT     │
│ 출처 [1] [2]                               │
│                         [ 이 패키지로 학습 시작 ]│
└───────────────────────────────────────────┘
```
- 버튼을 누르기 전에는 아래 카드 자리에 "패키지를 누르면 설명이 보입니다"를 표시합니다.

## 6. 라인 시뮬레이션
```
┌───────────────────────────────────────────┐
│ QFN 라인 실습         ■■■□□□□□  3/8        │
├───────────────────────────────────────────┤
│ 공정 3 · 다이 어태치                         │
│                                            │
│ 접착제 양                                   │
│  ( ) 1. 부족   (●) 2. 권장   ( ) 3. 과다     │
│                                            │
│ 경화 조건                                   │
│  ( ) 1. 덜 경화 ( ) 2. 권장  ( ) 3. 과경화   │
│                                            │
│ 이전 선택: 백그라인딩 2 · 웨이퍼 쏘잉 3        │
```

- 진행 중에는 등급(권장/주의/불량)을 보여주지 않습니다. 학생이 이유를 생각하며 고르게 하기 위해서입니다. [가설]
- 변수를 모두 고르기 전에는 [다음 공정]이 비활성입니다.

## 7. 최종 판정
```
┌───────────────────────────────────────────┐
│ 최종 판정:  ✗ 불량                          │
├───────────────────────────────────────────┤
│ 원인: 웨이퍼 쏘잉 · 이송 속도 "빠르게"        │
│ 연결: 백그라인딩 "너무 얇게" 때문에            │
│       주의 → 불량으로 바뀜                   │
│ 이유: 얇은 웨이퍼는 빠른 절단에서 깨지기 쉬움 [1]│
├───────────────────────────────────────────┤
│ 공정별 선택 요약                 [펼치기 ▾]  │
│ 백그라인딩 1 주의 · 쏘잉 3 불량 · 다이 어태치 2 권장 …│
├───────────────────────────────────────────┤
│ [ 웨이퍼 쏘잉 다시 학습 ]     [ 처음부터 다시 ]│
└───────────────────────────────────────────┘
```
- 판정 표시: 정상(✓), 신뢰성 위험(!), 불량(✗). 색만으로 구분하지 않고 기호와 글자를 함께 씁니다.

## 추가 (2026-10-17)
- 라인 시뮬레이션: "공정마다 결과 바로 보기" 체크박스. 켜면 선택지 아래에 "이 공정 결과"(등급, 문제, 이유, 완성 패키지에서의 영향)가 보입니다.
